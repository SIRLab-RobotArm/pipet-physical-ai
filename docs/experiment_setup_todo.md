# 실험 세팅 할 일

### 15.1 하드웨어 사실 (확인됨)

**Mark7은 평행 그리퍼가 아니라 손가락 5개짜리 손이다.**
`pipet_hand_mark7.xacro`와 STL 메시 실측:

| 부위 | 크기 |
|---|---|
| 손바닥(base_link) | 80 × 58 × 100 mm |
| 손가락 4개가 늘어선 폭 | 약 93 mm |
| 손가락 길이 (마디 2개) | 약 85~90 mm |
| 마디당 굽힘 한계 | 1.396 rad = 80° (총 160°) |

`grip_presets.yaml`의 `grasp`는 **검지·중지·약지·새끼를 350으로 감고 엄지는 0**이다.
즉 네 손가락으로 손바닥 쪽으로 감아쥔다(원래 피펫용 3-손가락 설정에서 검지를 추가함).
**"최대 개방 폭"이라는 단일 수치가 없으므로 실측이 필요하다.**

### 15.2 물체 (PVC 확보됨, 최종 사양)

㈜대성산업 비압력용 경질 폴리염화비닐관(PVC-U), KS M 3404,
SDR 9 / VN 직관, 규격 20×4 m, KS 인증 제6666호를 25 cm로 절단해 사용한다.
오버그립과 내부 무게추는 사용하지 않고, 예비 물체 없이 동일한 한 물체를 사용한다.

| 항목 | 값 | 상태 |
|---|---|---|
| 길이 | 250 mm | 확인됨 |
| 바깥지름 | 25 mm | 확인됨 |
| 속지름 | 20 mm | 확인됨 |
| 관벽 두께 | 약 2.5 mm | 외·내경 차이로 계산 |
| 표면 | PVC 원재질, 오버그립 없음 | 결정됨 |

현재 고정 카메라 RGB 화면에서 PVC의 외곽선, 상단 구멍과 그림자가 식별된다.
본 실험은 RGB-only이므로 depth 품질은 평가하지 않는다.

길이 25 cm와 지름 25 mm는 이론적으로 전도에 민감하지만, 현재 실제 테이블에서
안정적으로 서는 것을 육안 확인했다. 파일럿에서 반복 접근 시 전도가 발생하는지만
계속 기록한다.

### 15.3 할 일

(아래 단계 표시 ①~⑤는 실험 조건 A~D와 무관한 진행 단계 번호다)

**① 물체·환경 확정**
- [x] PVC 길이·외경·내경 확인 (250/25/20 mm)
- [x] 오버그립 없이 사용
- [x] 테이블에서 안정적으로 서는지 육안 확인
- [ ] `grasp` 프리셋으로 들어 올림을 육안 확인
- [ ] 커튼 치고 실내등만 쓰는 것을 **고정 규칙**으로 (결정됨)

**② 물건·카메라**

- [x] 카메라와 테이블 고정

**③ 로봇 앞에서 (G1)**

- [ ] 격자 간격 확정 (닿는 범위 안에서 최대한 넓게)
- [ ] 테이블에 동일한 작은 표식 표시 — grid 9 + Q 4 + pilot 2 = 물리 15곳

**④ RGB 카메라 (G2)**

- [ ] 노출·gain·WB 고정 후 **readback으로** 실제 적용 확인

**⑤ 그다음**
