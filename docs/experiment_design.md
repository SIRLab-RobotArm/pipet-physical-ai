# ACT RGB-only 데이터 수집 및 평가 설계

이 문서는 본 실험의 데이터 위치, episode 수, A~D 학습 조건과 평가 위치를 정의하는
단일 기준 문서다. 다른 문서와 충돌하면 사전등록이 동결되기 전까지 이 문서를 우선한다.

> 실제 진행 상태와 계획 대비 편차는 [프로젝트 인수인계](HANDOFF.md)를 함께 확인한다.
> 2026-08-20 현재 수집·변환·12개 모델 학습은 완료되었고 본 평가는 미시작이다.

## 1. 실험 범위

- 입력은 고정 오버헤드 D435의 **RGB 영상만** 사용한다.
- Depth 스트림, RGB-depth 정렬, depth QA 및 RGB-D 보조 실험은 수행하지 않는다.
- 물체·카메라·조명·그리퍼는 고정하고, 시연 데이터의 **개수와 XY 위치 분포**만 비교한다.
- ACT의 넓은 외삽 일반화를 주장하지 않는다. 시연 위치 재현을 주평가로, 동일 격자
  내부의 가까운 위치 보간을 보조평가로 삼는다.

## 2. 위치 배치

안전 workspace 안에 3×3 수집 격자를 둔다. 중심은 `G5`, 간격은 실제 도달 범위와
카메라 가림을 확인한 뒤 `dx`, `dy`로 동결한다.

```text
G1 ───── G2 ───── G3
│    Q1   │   Q2    │
G4 ───── G5 ───── G6
│    Q3   │   Q4    │
G7 ───── G8 ───── G9
```

Indy base 좌표에서 중심을 `(x0, y0)`라고 하면 수집 위치는 다음과 같다.

| 위치 | XY 좌표 |
|---|---|
| G1 | `(x0-dx, y0+dy)` |
| G2 | `(x0, y0+dy)` |
| G3 | `(x0+dx, y0+dy)` |
| G4 | `(x0-dx, y0)` |
| G5 | `(x0, y0)` |
| G6 | `(x0+dx, y0)` |
| G7 | `(x0-dx, y0-dy)` |
| G8 | `(x0, y0-dy)` |
| G9 | `(x0+dx, y0-dy)` |

`Q1~Q4`는 각각 인접한 네 grid 위치의 산술 중심이다. 모두 3×3 격자의 convex hull
내부에 있으므로 외삽 위치가 아니라 가까운 보간 위치다.

## 3. 본 데이터 수집: 220개

개수는 **검수와 제외 규칙을 통과한 usable demonstration** 기준이다. 실패·discard·손상
episode는 220개에 포함하지 않으며 사유는 별도 기록한다.

| 위치 | 수집 개수 |
|---|---:|
| G1 | 20 |
| G2 | 20 |
| G3 | 20 |
| G4 | 20 |
| G5 | 60 |
| G6 | 20 |
| G7 | 20 |
| G8 | 20 |
| G9 | 20 |
| **합계** | **220** |

위치별로 블록 수집하지 않는다. 사전에 생성한 무작위·균형 schedule로 위치를 섞어
시간, 운영자 피로, 조명 변화가 특정 위치에 몰리지 않게 한다.

운영은 두 단계로 한다. 1단계는 G1~G9를 20 round 순환해 각 20개, 총 180개를
모은다. 2단계는 G5 추가 40개를 수집한다. 2단계도 한 번에 몰아서 수집하기보다 전체
세션 사이에 나누어 배치한다. 현재 Xbox 노드는 1단계 schedule만 자동 생성하므로
본 수집 전 G5-only 추가 schedule과 중단/재개 인덱스를 구현·검증해야 한다.

## 4. A~D 학습 조건

220개 원본에서 아래 부분집합을 만들어 사용한다. episode 선택 규칙과 UUID 목록은
모델 결과를 보기 전에 immutable manifest로 고정한다. 세 모델 seed 0, 1, 2는 같은
조건 manifest를 사용해 데이터 차이가 아니라 학습 난수 차이를 비교한다.

| 조건 | 위치별 episode | 합계 | 비교 목적 |
|---|---|---:|---|
| A | G5에서 60개 | 60 | 한 위치 집중 |
| B | G1·G6·G8에서 각 20개 | 60 | 같은 개수, 3곳 분산 |
| C | 아래 3×3 배분 | 60 | 같은 개수, 9곳 분산 |
| D | G1~G9에서 각 20개 | 180 | 같은 9곳 분포, 개수 증가 |

조건 C의 정확한 배분은 다음과 같다.

```text
G1=7   G2=6   G3=7
G4=7   G5=6   G6=7
G7=7   G8=6   G9=7
```

주요 비교는 `A vs B vs C`로 60개 고정 시 위치 분포 효과를 보고, `C vs D`로 9개
위치 고정 시 데이터 개수 효과를 본다. 모든 조건은 RGB-only이며 조건마다 ACT 학습
seed 3개를 사용하므로 본 모델은 총 12개다.

모든 본 학습은 조건과 seed에 관계없이 **100,000 optimization step**으로 고정한다.
체크포인트는 20,000 step마다 저장하므로 `20k`, `40k`, `60k`, `80k`, `100k`가
남는다. 중단된 학습을 이어서 재개하지 않으며, 본 평가는 각 실행의 `100k` 최종
체크포인트만 사용한다.

## 5. 평가 위치와 rollout 수

12개 모델을 모두 동일한 8개 위치에서 평가한다.

| 평가 ID | 물리 위치 | 성격 |
|---|---|---|
| `eval_1` | G5 | 수집 grid와 동일 |
| `eval_2` | G1 | 수집 grid와 동일 |
| `eval_3` | G6 | 수집 grid와 동일 |
| `eval_4` | G8 | 수집 grid와 동일 |
| `eval_5` | Q1 | 격자 내부 보간 |
| `eval_6` | Q2 | 격자 내부 보간 |
| `eval_7` | Q3 | 격자 내부 보간 |
| `eval_8` | Q4 | 격자 내부 보간 |

`eval_1~eval_4`의 teach-in 값은 대응하는 grid 좌표를 그대로 복사해 같은 물리 위치에
서로 다른 좌표가 생기지 않게 한다. Q 위치는 어떤 demonstration에도 포함하지 않는다.

- 위치당 2회 rollout
- 모델당 `8 × 2 = 16회`
- `4조건 × 3 seeds = 12모델`
- 전체 `12 × 16 = 192회`

주평가 결과는 grid 동일 위치 4곳의 성공률과 실패 유형이다. Q1~Q4 결과는 격자 내부
보간에 대한 보조 결과로 분리해 보고한다. 각 평가점에서 가장 가까운 해당 조건의 학습
위치까지 거리 `d`도 기록한다.

## 6. Pilot과 물리 표식

`pilot_1`, `pilot_2`는 조작 연습, 파이프라인 점검, 성공 기준 조정에만 사용하며 본
학습·평가 데이터에서 제외한다. 파일에는 19개 position ID가 있지만 서로 다른 물리
위치는 `grid 9 + Q 4 + pilot 2 = 15곳`이다.

표식은 PVC 바닥에 가려지는 동일한 크기·색의 작은 표시로 만들고, 위치마다 다른 시각
단서를 주지 않는다.
